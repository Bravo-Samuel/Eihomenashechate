# Environment Variables Reference

> Generated by MEP-605. Base every production setup on this document.
> **Never commit secret values to source control.**

---

## API Server (`artifacts/api-server`)

### Required

| Variable | Purpose | Default | Notes |
|---|---|---|---|
| `DATABASE_URL` | PostgreSQL connection string | — | **Server exits on startup if missing.** Format: `postgresql://user:pass@host:5432/db` |

### Auth (Replit Auth)

| Variable | Purpose | Required? | Default | Notes |
|---|---|---|---|---|
| `SESSION_SECRET` | Session cookie signing secret | Required | — | Must be at least 32 characters; never commit the value |
| `REPL_ID` | Managed Replit Auth client identifier | Required | — | Auto-injected by Replit |
| `REPLIT_AUTH_CLIENT_ID` | Optional explicit Replit Auth client identifier | Optional | `REPL_ID` | Use only when the managed Auth setup provides a distinct client ID |
| `ISSUER_URL` | Replit OIDC issuer | Optional | `https://replit.com/oidc` | Override only for a compatible OIDC issuer |

Clerk variables may remain temporarily during the staged identity migration so existing
Clerk users and organization-admin compatibility can be verified. They are not required
for the new Replit Auth sign-in flow.

### AI Providers

All three are optional. The gateway tries OpenAI → Gemini → Grok in order. If none are set, `/api/chat` returns 503.

| Variable | Purpose | Required? | Default | Notes |
|---|---|---|---|---|
| `OPENAI_API_KEY` | OpenAI API key (primary AI provider) | Optional | — | GPT-4o-mini used by default |
| `GOOGLE_API_KEY` | Google Gemini API key (fallback) | Optional | — | |
| `GROK_API_KEY` | xAI Grok API key (final fallback) | Optional | — | |

### Push Notifications (WebPush/VAPID)

| Variable | Purpose | Required? | Default | Notes |
|---|---|---|---|---|
| `VAPID_PUBLIC_KEY` | VAPID public key for WebPush | Recommended | Hardcoded fallback | Use `web-push generate-vapid-keys` to generate |
| `VAPID_PRIVATE_KEY` | VAPID private key for WebPush | Recommended | — | Must be 32-byte base64url encoded |
| `VAPID_SUBJECT` | VAPID subject (contact URL/email) | Optional | `mailto:admin@menashecalendar.app` | Must be a `mailto:` or `https://` URL |

### Payments

| Variable | Purpose | Required? | Default | Notes |
|---|---|---|---|---|
| `RAZORPAY_KEY_ID` | Razorpay API key ID | Optional | — | Payment routes return 503 if missing |
| `RAZORPAY_KEY_SECRET` | Razorpay API key secret | Optional | — | Required alongside `RAZORPAY_KEY_ID` |

### Server Configuration

| Variable | Purpose | Required? | Default | Platform |
|---|---|---|---|---|
| `PORT` | HTTP port to bind | Optional | `8080` | All |
| `NODE_ENV` | Environment mode | Optional | `development` | All |
| `LOG_LEVEL` | Pino log level | Optional | `info` | All |
| `ALLOWED_ORIGINS` | Comma-separated CORS allowed origins | Recommended in prod | — | All; falls back to `REPLIT_DOMAINS` |

### Replit-Only

| Variable | Purpose | Required? | Notes |
|---|---|---|---|
| `REPLIT_DOMAINS` | Comma-separated Replit domains | Replit only | Auto-injected by Replit; used as CORS fallback |
| `PRIVATE_OBJECT_DIR` | GCS private object directory | Replit only | Used by object storage sidecar |
| `PUBLIC_OBJECT_SEARCH_PATHS` | GCS public search paths | Replit only | Used by object storage sidecar |

> **Note on Object Storage:** The GCS client authenticates through a Replit internal sidecar at `http://127.0.0.1:1106`. This is Replit-specific and will not function on Railway, Render, or Fly.io without replacing the credential block in `objectStorage.ts` with a standard GCS service account.

## Web Frontend (`artifacts/menashe-calendar`)

These variables are consumed at **Vite build time** and embedded in the compiled bundle. They must be set in the CI/CD environment (Netlify build settings, Replit deployment secrets) — not only at runtime.

| Variable | Purpose | Required? | Default | Platform |
|---|---|---|---|---|
| `VITE_UPI_ID` | UPI payment ID (shown in payment UI) | Optional | — | India payments |
| `API_URL` | Backend URL for Vite dev proxy | Dev only | `http://localhost:8080` | Development only; **not used in production builds** |
| `BASE_PATH` | Vite `base` path override | Optional | `""` (root) | Set only when deploying to a subdirectory |
| `PORT` | Vite dev server port | Dev only | `5000` | Development only |
| `NODE_ENV` | Vite build environment | Optional | `development` | Set to `production` in CI |

> **Auth note:** The browser uses the same-origin `/api/auth/*` routes and an HttpOnly session cookie. No browser-exposed auth key is required.

## Mobile App (`artifacts/menashe-mobile`)

Expo public variables are embedded at build time by EAS. They must be added to EAS secrets or `eas.json` environment blocks for each build profile.

| Variable | Purpose | Required? | Default | Notes |
|---|---|---|---|---|
| `EXPO_PUBLIC_DOMAIN` | Production API server domain | **Required** | — | All API calls are `https://${EXPO_PUBLIC_DOMAIN}/api/...`. **Currently missing from all EAS build profiles** — standalone builds will fail without it. |
| `EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY` | Clerk publishable key | **Required** | — | Dev script maps it from `$CLERK_PUBLISHABLE_KEY`; EAS profiles do not — must be added explicitly. |

- `VAPID_SUBJECT`
